# Deteksi Plagiarisme Cepat & Akurat

Aplikasi web berbasis Python untuk mendeteksi kemiripan teks. Bandingkan
dokumen teks atau PDF dengan sumber referensi menggunakan TF-IDF dan
Cosine Similarity.

## Fitur
- Input berupa teks langsung atau file PDF
- Perbandingan dengan sumber referensi
- Skor kemiripan dalam persen

## Cara menjalankan
pip install -r requirements.txt
uvicorn main:app --reload
